# SECURITY.md

## Vulnerability Disclosure

### Reporting a vulnerability

If you find a security vulnerability, then you can:

- [send a support ticket](https://docs.2i2c.org/support/) (:star: preferred approach)
- [open a private security issue](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately) (GHSA) in our GitHub repository

### Known vulnerabilities

Our software stack largely depends on subprojects across the Project Jupyter ecosystem. Known vulnerabilities are tracked using the [CVE vendor ID 15653](https://www.cvedetails.com/vulnerability-list/vendor_id-15653/Jupyter.html) for Jupyter.

[GitHub provides dependabot alerts](https://docs.github.com/en/code-security/supply-chain-security/managing-vulnerabilities-in-your-projects-dependencies/about-alerts-for-vulnerable-dependencies) about vulnerable dependencies. If your supply chain includes Jupyter projects, these alerts can help you respond to vulnerabilities quickly and easily.

### Bug bounty programs

We do not run bug bounty programs, and do not reward vulnerability discovery.
